# ALT Magnifier — 验收测试页

打开方式（任选其一）：

- 在 `edge://extensions` 里加载扩展后，直接用浏览器打开本文件
  （manifest 已声明 `file:///*`，本地文件也能生效），路径形如
  `file:///E:/Code/ALT Magnifier/test/test-page.html`
- 或者用命令行起一个静态服务器：`python -m http.server 8123`，然后访问
  `http://localhost:8123/test/test-page.html`

页面**左上角**有一个检测面板，它会自己验证「元素位置是否真的没变」，不需要人眼比对。

> 自动化测试与维护者向的说明见仓库根目录的 [`TESTING.md`](../TESTING.md)；
> 本文件只讲人工验收。

## 一、必测项（人眼 30 秒版）

| # | 操作 | 期望结果 |
|---|---|---|
| 1 | 鼠标停在中间那段长文的**某一个字**上，按住 `Alt` 向下滚 | 那个字**钉在原地一动不动**，周围向外扩张 |
| 2 | 继续滚到 8 倍以上 | 没有任何元素「跳一下」或错位；文字边缘清晰不模糊 |
| 3 | 松开 `Alt` | 约 600ms 后自动还原，且观感上仍停在刚才看的那一段 |
| 4 | 放大后按 `Esc` | 立刻还原，视口中心还是放大时看到的内容 |
| 5 | 放大后按 `Alt`+`0` | 回到**按下 Alt 时**的原地（滚回原点） |
| 6 | 对着右上角 `fixed` 顶栏 / 右下角 `fixed` 悬浮球滚轮 | 它们是画面的一部分：一起被放大，并在向下滚时**一起滚走**（这正是「图片式放大」的预期） |
| 7 | 对着 `sticky` 侧栏滚轮 | 同上，随画面滚走，不脱离、不闪烁 |
| 8 | 对着 `background-attachment: fixed` 的大色块滚轮 | 开启「修复固定背景」时，色块边界与被放大后的框**严丝合缝**，不出现背景与主体错位 |
| 9 | 对着内嵌滚动容器（虚线框那块）滚轮 | 里面的内容也一起被放大，且与外层保持同一比例 |
| 10 | 对着 iframe 里的内容滚轮 | iframe 内容同步放大，与页面其余部分比例一致 |
| 11 | 一直滚到 32 倍 | 不卡死、不白屏；滚动条仍然能把画面拖到页面角落 |
| 12 | 不按 `Alt` 直接滚轮 | 页面正常滚动，**没有任何**放大行为、没有卡顿感 |

## 二、自动漂移检测（重点）

1. 打开本页，左上角面板会先自检「扩展是否注入本页」。
2. **按住 `Alt` 滚动滚轮放大到 4 倍左右**，然后松开 `Alt`。
3. 面板会自动打印结果，形如：

```
实测倍率 k = 4.03（kx=4.03, ky=4.03）
鼠标锚点 ≈ (640.00, 420.00)
参考元素 16 个｜符合比例 16 个
✓ 通过：零位移，页面确实是整体缩放的。
```

若是某个元素真的错位，会变成这样，并且**直接给出位移像素数**：

```
✗ 位移 2 个：
  bigbg（fixed/sticky，需人工判断） 位移 12.34px，尺寸偏差 0.20px
```

> 注意：`position: fixed` / `sticky` 的元素合理地会随画面移动，面板会把它们
> 单独标注，需要你人工判断 —— 判据是它们**是否作为画面的一部分整体缩放**，
> 而不是它们有没有移动。

判定标准（脚本内部实现）：

- 设放大前某元素相对鼠标锚点（视口坐标 ax, ay）的偏移为 `(x1-ax, y1-ay)`，
  放大后为 `(x2-ax, y2-ay)`。若元素完全没有位移，则两者之比必须**处处等于 k**。
- 脚本对 `x`、`y` 两个方向分别求解 `k = (x2-ax)/(x1-ax)`，要求两者一致且等于
  实际倍率；同时对元素宽高比也做同样检查。
- 只有**绘制期定点修复**（例如 `background-attachment` 覆写、站点专属补丁）
  才会合理地产生偏差，这类元素会被单独列出来并标注原因。

## 三、已知会「合理地」偏离的元素

以下几类元素本身没有布局位移，但受影响于它们自身的渲染机制，属于预期：

- `background-attachment: fixed` 的大背景（未开启修复时会与主体错位）。
- 站点自己用 `getBoundingClientRect()` 计算视觉坐标再写回布局属性的元素
  （拖拽跟随、进度条把手等）。**这类元素只有在站点同时监听滚动/resize 时才会抖**，
  本扩展不派发任何事件，所以正常情况不会触发。
- 视频播放器的控制条自动隐藏 —— 那是播放器自身逻辑，与缩放无关。
